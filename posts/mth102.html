📘 Module 1: Functions of Real Variables

Core Concepts

Definition: A function f from set X (Domain) to set Y (Codomain) assigns exactly one f(x) ∈ Y to every x ∈ X.

  • Domain: All valid inputs.
  • Range: Actual outputs. (Range ⊆ Codomain).
  • Even: f(-x) = f(x) (Symmetry over Y-axis).
  • Odd: f(-x) = -f(x) (Rotational symmetry).
  • Periodic: f(x+T) = f(x). Fundamental period T.
  • Composite: (f ∘ g)(x) = f(g(x)). Domain: x ∈ D_g and g(x) ∈ D_f.
  • Difference Quotient: (f(x+h)-f(x))/h (Slope of secant line).
Q1 (Domain & Range): Find the domain and range of f(x) = 3x / (x² - 4).
Q2 (Even/Odd): Determine if f(x) = x³ sin(x) is even, odd, or neither.
Q3 (Composite): Given f(x) = 1/x and g(x) = √(x-2), find (f ∘ g)(x) and its domain.
Q4 (Periodicity): What is the fundamental period of f(x) = cos(4x)?
Q5 (Difference Quotient): Compute (f(x+h)-f(x))/h for f(x) = 2x² - 3x. Simplify.
Solutions:
A1: Domain: x ≠ ±2. Range: ℝ.
A2: f(-x) = (-x)³ sin(-x) = (-x³)(-sin x) = x³ sin x = f(x) → Even.
A3: (f ∘ g)(x) = 1/√(x-2). Domain: x > 2.
A4: T = 2π/4 = π/2.
A5: f(x+h) = 2x²+4xh+2h²-3x-3h. Subtract f(x): 4xh+2h²-3h. Divide by h: 4x + 2h - 3.

📘 Module 2: Limits & Limit Theorems

Core Concepts

Intuition: A limit lim(x→a) f(x) = L means as x gets arbitrarily close to a (from both sides), f(x) gets arbitrarily close to L.

  • Limit Theorems: Constant, Sum, Product, Quotient, Power, Root.
  • Squeeze Theorem: If g(x) ≤ f(x) ≤ h(x) and lim g = lim h = L, then lim f = L.
  • Infinite Limits: lim(x→a) 1/(x-a)² = +∞.
  • Indeterminate Forms: 0/0, ∞/∞. Solve via factorization or rationalization.
Q1: Evaluate lim(x→3) (x² - 9)/(x - 3).
Q2: Evaluate lim(x→∞) (3x² + 2x)/(5x² - 4).
Q3: Use Squeeze Theorem: If 1 - x²/2 ≤ f(x) ≤ 1 + x²/2, find lim(x→0) f(x).
Q4: Evaluate lim(x→0) sin(2x)/x.
Solutions:
A1: Factor: (x-3)(x+3)/(x-3) = x+3 → 6.
A2: Divide by x²: (3 + 2/x)/(5 - 4/x²) → 3/5.
A3: Both bounds approach 1, so 1.
A4: Let u = 2x: (sin(2x)/2x)·2 → 2.

📘 Module 3: Continuity

Core Concepts

A function is continuous at x = a if three conditions are met:

  1. f(a) is defined.
  2. lim(x→a) f(x) exists.
  3. lim(x→a) f(x) = f(a).
  • Types of Discontinuities: Removable (hole), Jump (step), Infinite (vertical asymptote).
  • Intermediate Value Theorem (IVT): If f is continuous on [a,b] and k is between f(a) and f(b), then there exists c ∈ (a,b) such that f(c) = k.
Q1: Is f(x) = (x²-4)/(x-2) continuous at x=2? If not, how can it be redefined?
Q2: Find k that makes f(x) = {x² + k, x ≤ 1; 2x + 3, x > 1} continuous at x=1.
Q3: Show that f(x) = x³ - x - 1 has a root between 1 and 2 using IVT.
Solutions:
A1: No. f(2) undefined. Factor: (x-2)(x+2)/(x-2) = x+2. Redefine f(2) = 4.
A2: Left limit: 1+k. Right limit: 5. Set 1+k=5 → k=4.
A3: f(1) = -1 (negative), f(2) = 5 (positive). By IVT, root exists between 1 and 2.

📘 Module 4: Differentiation from First Principles

Core Concepts

Definition of Derivative: f'(x) = lim(h→0) (f(x+h)-f(x))/h.

  • Constant rule: d/dx(c) = 0.
  • Power rule: d/dx(xⁿ) = nxⁿ⁻¹.
  • Sum rule: d/dx(f+g) = f' + g'.
Q1: Using first principles, find the derivative of f(x) = x².
Q2: Using first principles, find the derivative of f(x) = √x.
Q3: Differentiate f(x) = 5x⁴ - 3x² + 7 using the power rule.
Solutions:
A1: f'(x) = lim(h→0) ((x+h)² - x²)/h = lim(h→0) (2xh + h²)/h = 2x.
A2: f'(x) = lim(h→0) (√(x+h) - √x)/h = 1/(2√x).
A3: f'(x) = 20x³ - 6x.

📘 Module 5: Advanced Differentiation

Core Concepts

  • Product Rule: (uv)' = u'v + uv'.
  • Quotient Rule: (u/v)' = (u'v - uv')/v².
  • Chain Rule: dy/dx = (dy/du)·(du/dx).
  • Derivatives: d/dx sin x = cos x, d/dx cos x = -sin x, d/dx eˣ = eˣ, d/dx ln x = 1/x.
  • Implicit Differentiation: Differentiate both sides with respect to x and solve for dy/dx.
Q1: Differentiate y = (3x² + 1)⁵ (Chain Rule).
Q2: Differentiate y = x² sin(x) (Product Rule).
Q3: Differentiate y = ln(x)/x² (Quotient Rule).
Q4: Find dy/dx for x² + y² = 25 (Implicit Differentiation).
Solutions:
A1: 30x(3x²+1)⁴.
A2: 2x sin x + x² cos x.
A3: (1 - 2ln x)/x³.
A4: -x/y.

📘 Module 6: Applications of Derivatives

Core Concepts

  • Increasing/Decreasing: f'(x) > 0 → increasing; f'(x) < 0 → decreasing.
  • Critical Points: Where f'(x) = 0 or undefined.
  • First Derivative Test: Sign change of f' determines local max/min.
  • Second Derivative Test: f''(x) > 0 → local min; f''(x) < 0 → local max.
Q1: Find critical points of f(x) = x³ - 3x² - 9x + 5 and classify them.
Q2: Find intervals where f(x) = x³ - 3x is increasing/decreasing.
Q3 (Optimization): Find two positive numbers whose sum is 20 and product is maximum.
Solutions:
A1: f'(x) = 3(x-3)(x+1). Critical points: x = -1 (local max), x = 3 (local min).
A2: Increasing on (-∞, -1) and (1, ∞); Decreasing on (-1, 1).
A3: Numbers: 10 and 10.

📘 Module 7: Integration as Anti-differentiation

Core Concepts

Indefinite Integral: ∫ f(x) dx = F(x) + C, where F'(x) = f(x).

  • Power Rule: ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C.
  • Special Cases: ∫ 1/x dx = ln|x| + C, ∫ eˣ dx = eˣ + C.
  • u-Substitution: Reverse of Chain Rule.
Q1: Evaluate ∫ (3x² + 4x - 1) dx.
Q2: Evaluate ∫ 2x/(x²+1) dx (u-substitution).
Q3: Evaluate ∫ e³ˣ dx.
Solutions:
A1: x³ + 2x² - x + C.
A2: ln(x²+1) + C.
A3: (1/3)e³ˣ + C.

📘 Module 8: Advanced Integration Techniques

Core Concepts

  • Integration by Parts: ∫ u dv = uv - ∫ v du.
  • Partial Fractions: Decompose rational functions into simpler fractions.
  • Trigonometric Substitution: Handle radicals like √(a² - x²).
Q1: Evaluate ∫ x eˣ dx (Integration by Parts).
Q2: Evaluate ∫ 1/(x² - 1) dx (Partial Fractions).
Q3: Evaluate ∫ x cos(x) dx (Integration by Parts).
Solutions:
A1: x eˣ - eˣ + C.
A2: (1/2) ln|(x-1)/(x+1)| + C.
A3: x sin x + cos x + C.

📘 Module 9: The Fundamental Theorem of Calculus & Area

Core Concepts

  • FTC Part 1: d/dx ∫ₐˣ f(t) dt = f(x).
  • FTC Part 2: ∫ₐᵇ f(x) dx = F(b) - F(a).
  • Area under curve: ∫ₐᵇ f(x) dx.
  • Area between curves: ∫ₐᵇ (Top - Bottom) dx.
